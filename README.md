# Make It Cute ♡

Cute DIYs for kids, tweens and teens: squishies, crochet, bows, baking, nail art, room decor and more.
**Designed and created by Charice**, with help from Dad.

## What's in here
| Folder | What it is |
|---|---|
| `web/` | The app itself (`index.html`) plus fonts, icons, videos and the privacy page. **Edit the app here.** |
| `android/` | Android Studio project for Google Play (made with Capacitor) |
| `ios/` | Xcode project for the App Store (made with Capacitor) |
| `store/` | Store listing text, screenshots, feature graphic, 1024 icon |
| `assets/` | Source images for the app icon and splash screen |
| `.github/workflows/` | Automations: publish the website, build the Android app |

## Making a change
1. Edit `web/index.html`.
2. Change `VERSION` at the top of `web/sw.js` (e.g. `mic-v4` → `mic-v5`).
3. Commit and push. The website updates itself in a minute or two.
4. For the phone apps, see PUBLISHING.md → "Updating".

See **PUBLISHING.md** for the full step-by-step to Google Play and the App Store.
